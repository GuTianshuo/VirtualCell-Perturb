## 4 Step 01：预处理（伪批量 + 差异检验 + 单细胞潜空间）

```bash
python scripts/01_preprocess.py --dataset replogle_k562_essential   # 30 s
python scripts/01_preprocess.py --dataset adamson                   # 6 s
```

**输入**：`data/raw/{dataset}/perturb_processed.h5ad`（GEARS 格式：`obs["condition"]` 形如 `GENE+ctrl` 或 `ctrl`，`var["gene_name"]`，`X` 为 log-normalized 稀疏矩阵）。

**内部做什么**

1. **解析条件**：`parse_condition` 把 `GENE+ctrl` / `ctrl+GENE` 归一成 `GENE`；只保留单基因扰动（含 `+` 的组合作废）；细胞数 ≥ `--min_cells 15` 的扰动才保留。
   - K562：1,092 个扰动保留，10,691 个对照细胞；
   - Adamson：86 个扰动，24,263 个对照。
2. **分块伪批量统计**（`vcp.data.group_mean_var`）：按 20,000 行分块，用形状 `(n_groups, chunk)` 的稀疏指示矩阵一次性算出每组的和、平方和 → 均值与总体方差。**永不 densify**（峰值内存约 3.8 GB）。
3. **差异检验**（`welch_t` + `bh_fdr`）：每个扰动 vs 对照，Welch t（Welch-Satterthwaite 自由度，不做等方差假设）→ 双侧 p → 按行 BH-FDR。
4. **单细胞潜空间**：`fit_cell_pca` 在"对照 5,000 个细胞 + 每个扰动 40 个细胞"的分层抽样上拟合 100 维 PCA（以对照均值为中心），再把**所有细胞**投影成 100 维坐标。
   - K562：100 维解释 15.5% 总方差；Adamson 27.9%。

**输出**

| 文件 | 字段 |
|---|---|
| `data/processed/{ds}_pseudobulk.npz` | `genes`(5000)、`perts`(1092)、`ctrl_mean/ctrl_var`、`pert_mean/pert_var`、`n_cells`、`tstat`、`fdr`、`extra_target_idx`（靶基因在基因表中的下标）、`extra_pca_explained_var` |
| `data/processed/{ds}_cells.npz` | `Z`（每细胞 100 维坐标）、`label`（扰动下标 / 对照=N）、`components`、`ctrl_mean`、`explained_var`、`barcodes` |

**日志里要检查的数字**（K562）

```
perturbations kept: 1092 (min_cells=15); control cells: 10691
#DEG (FDR<0.05) per perturbation: median 283, mean 616, max 3045
target gene measured for 412 perts; median target log-FC -0.577
```

**坑**

- Welch t 的**自由度分母不能加绝对 ε**：低表达基因的平方标准误约 1e-10，加 1e-8 会让 df 塌到 1、p 值虚高（曾导致"完全敲低"的靶基因不显著）。现已与 `scipy.stats.ttest_ind(equal_var=False)` 逐位一致，并有回归测试。
- `anndata` 用 `backed="r"` 读，避免一次性载入 2.9 GB。
- 这里拟合的 PCA 是**部署用**的（全部扰动）；评测用的 PCA 在 05/11 里每折重拟合，不要混用。

## 5 Step 02：先验知识嵌入（把基因变成向量）

```bash
python scripts/02_build_embeddings.py
```

**输入**：`pseudobulk.npz`（拿到扰动基因列表与全部测量基因）+ `gene2go.pkl` + STRING 两个 gz + GenePT pickle。

**内部做什么**（`src/vcp/embeddings.py`）

1. **GO（128 维）**：基因 × GO 术语二值矩阵 → 去掉出现 <3 个基因的术语 → **TF-IDF** → `TruncatedSVD(128)` → 行 L2 归一化。
   - 关键设计：先在所有"测量基因 ∪ 扰动基因"上拟合变换，再用**同一套** vocabulary/IDF/SVD 嵌入额外基因（`extra_genes`），保证"加入新基因不会改变已有基因的向量"。
   - 确定性：术语按 `sorted(set(...))` 排序，避免 Python 字符串哈希随机化导致跨进程不可复现（踩过的坑）。
2. **PPI（128 维）**：STRING `combined_score ≥ 700` 建图 → 度归一化 $P=D^{-1/2}AD^{-1/2}$ → $M=P+P^2$ → `TruncatedSVD(128)` → 归一化。
3. **GenePT（128 维）**：从 pickle 取 GPT-3.5 文本嵌入 → 在"测量基因 ∪ 扰动基因"上 `PCA(128)` → 归一化（新基因用同一 PCA 变换）。
4. **输出两侧**：扰动基因（1,137 个，两数据集并集）与**全基因宇宙**（21,449 个）各一份；每源附带 `*_mask`（可用性）。
   覆盖率：扰动基因 GO 99.6% / PPI 97.6% / GenePT 99.5%；全宇宙 88.0% / 75.5% / 91.2%。

**输出**：`data/processed/pert_embeddings.npz`（评测用）、`data/processed/gene_universe_embeddings.npz`（部署用，任意基因可查）。

**验证**：脚本会打印与已有文件的 `max |diff|`（复现检查，应为 0.00e+00）。

**坑**：GenePT 文件在 zip 里，编码是 pickled dict（约 9.4 万个基因）；`02` 会自动解压并在找不到时报错降级（`genept` 源缺失时后续模型自动用三源）。

## 6 Step 03b：开发集超参扫描（只在开发集上）

```bash
python scripts/03b_dev_sweep.py
```

**为什么单独一步**：模型设计必须在"不碰测试折"的前提下比较。开发集 = 第 0 折训练扰动中再划出的 10% 内部验证集（约 87 个基因）。

**做法**：`03_benchmark.py --dev` 模式（`tr_all, te = tr, va`），只训练 PerturbFormer，扫 10 组配置（topk、n_heads、lam_dir、d_model、dropout、basis_k）。

**输出**：`results/{ds}/dev_sweep.csv`

**实测结果**（`dev_sweep.csv`）：各配置 dev Top-20 DEG Pearson 0.811–0.818、去偏 0.521–0.535 —— **极差 0.007 / 0.015，与种子噪声（同配置 sd≈0.002–0.007）同量级**，所以最终取默认配置，而不是挑最优。这是"结论不依赖调参"的依据。

## 7 Step 03：主评测（5 折未见基因 × 全部模型 + 消融）

```bash
python scripts/03_benchmark.py --dataset replogle_k562_essential --models all --n_ens 3   # 84 min
python scripts/03_benchmark.py --dataset adamson --models all --n_ens 3                   # 6.5 min
```

**输入**：`pseudobulk.npz` + `pert_embeddings.npz`。

**内部流程（每一折重复）**

```
fold f:  te = 第 f 折基因（20%），tr_all = 其余 80%
         tr, va = tr_all 内部 90/10 划分
         ① 折内特征：feats/masks = 静态三源 + response_embedding(Y[tr_all])   ← 折内重算，防泄露
         ② 折内 KD 比例：kd_frac = median(靶基因 扰动均值/对照均值) over tr_all
         ③ 训练/预测每个模型 → 每个模型一份 (P_te, 5000) 预测
         ④ 用 evaluate() 算 8 个指标 → 每扰动一行记录
         ⑤ 预测写入 oof 数组（每个基因恰好被写一次）
```

**模型清单**（36 行结果表）

- 平凡：`No-change`、`Mean-shift`
- 单源：`Linear-{go,ppi,genept,resp}`、`kNN-{go,ppi,genept,resp}`
- 多源：`Linear-concat(+KD)`、`kNN-concat(+KD)`
- 深度：`PerturbNet-attn/concat(+KD)`（d=128、2 层、4 头、PCA 基底 64）
- 本文：`PerturbFormer(+KD)`（知识核、top-20、2 头、3 种子集成）
- 消融：`no-{go,ppi,genept,resp}`、`no-dirloss`、`no-topk`、`concat-fusion`、`free-attention`（每个都带 +KD 版本）
- 另外：KD 规则在外部施加（`knockdown_rule`），所以每个模型都有"不带 KD / 带 KD"两行

**输出**

| 文件 | 内容 |
|---|---|
| `results/{ds}/summary.csv` | 每模型 8 个指标的平均（主表来源） |
| `results/{ds}/per_perturbation_metrics.csv` | 每折 × 每模型 × 每扰动一行（配对检验的输入） |
| `results/{ds}/oof_predictions.npz` | 所有模型的 OOF 预测（1,092 × 5,000）+ 注意力/邻居/门控（后续解释与 explorer 用） |
| `results/{ds}/folds.npy`、`config.json` | 划分与运行参数（可复现） |
| `results/replogle_k562_essential/main_table.md` | 带显著性星号的主表（由 09_figures.py 生成） |

**怎么验证这步成功**：`summary.csv` 里 `Mean-shift` 行的 `pearson_sys` 应恰好为 0.000、`rank` 为 0.500；`No-change` 全 0；`PerturbFormer+KD` 的 `pearson_sys` 应 ≈0.480。

**坑**

- 内存：`oof_predictions.npz` 约 700 MB（含 36 个模型的 1092×5000 预测），写入时用 `savez_compressed`。
- 全量 36 个模型在 4 核上约 84 分钟，中途不要在同一个 Python 进程里再跑 05_flow（内存）。
- 换划分时用 `--tag _seed1`，结果写进独立目录，`03c` 才能找到。

## 8 Step 03（续）/ 03c / 03d：稳健性与公平性

### 8.1 换两种划分重跑

```bash
python scripts/03_benchmark.py --dataset replogle_k562_essential \

python scripts/03_benchmark.py --dataset replogle_k562_essential \

```

只重跑 4 个主模型（20 行）以控制在 20 分钟内；结果写到 `results/replogle_k562_essential_seed{1,2}/`。

### 8.2 汇总 + 配对检验 + Holm 校正

```bash
python scripts/03c_split_robustness.py      # 2 秒
```

**做什么**：读 3 个划分目录的 `per_perturbation_metrics.csv`，对每个划分内部做**配对 Wilcoxon**（PerturbFormer vs 每个基线），输出 3 划分 × 6 指标的差值表，再对每个对照的 18 次比较做 **Holm 校正**。

**输出**：`split_robustness.csv`（长表）、`split_robustness.md`（报告 5.1b 的表 + 末尾校正后计数）。

**关键结论**：模型排序在 3 种划分中完全一致；对 kNN 未校正 15 胜/1 负/2 平，Holm 后 14/1/3。

### 8.3 基线同等调参

```bash
python scripts/03d_baseline_tuning.py       # 约 15 min
```

## 9 Step 04：测量噪声天花板

```bash
python scripts/04_noise_ceiling.py --dataset replogle_k562_essential
python scripts/04_noise_ceiling.py --dataset adamson
```

**做什么**：把每个扰动与对照的细胞随机二分成 A/B 两半 → 用 A 半算出的 Δ 当"预测"去评估 B 半的真实 Δ（`evaluate` 同一套指标）→ 得到半数据信度 r → **Spearman-Brown** 全数据信度 $2r/(1+r)$ → 完美预测器与全数据实测估计的相关上限 $\sqrt{2r/(1+r)}$（逐扰动求平均）。

**Adamson 结果**：上限 0.986 / 0.976 / 0.946（每扰动约 500 细胞，信度极高）。

**意义**：主表的 0.573 / 0.746 / 0.480 分别达到上限的 70% / 83% / 59%——绝对值要放在这个尺度下解读。

## 10 Step 05：单细胞条件流匹配（OT-CFM）

```bash
python scripts/05_flow.py                                  # 5 折，42 min
python scripts/05_flow.py --dev                            # 开发集版（不碰测试折），6 min
python scripts/05_flow.py --dev --var_cond                 # 失败的改进（留档）
```

**每一折的顺序（顺序很重要，是防泄露的关键）**

1. **折内 PCA**：`fit_cell_pca(..., fit_labels=tr_all)` —— 只用对照 + **训练扰动**的细胞拟合 100 维潜空间，测试扰动不决定坐标系；然后把全部细胞投影到该空间（`Z`）。
2. **折内 PerturbFormer**：3 个种子训练 → 对测试基因做正常预测 `p_te`；对训练基因做 **leave-self-out** 预测 `p_tr`（把自身从记忆库剔除）；两者都施加 KD 规则。
3. **条件**：$c_p=\hat\Delta_p B_{\text{PCA}}^\top$（100 维）。训练基因用 `p_tr`，测试基因用 `p_te`。
4. **检索相似扰动**（"借用细胞"基线用）：先验空间余弦相似度取训练扰动 top-5（训练侧留一），得到它们的潜空间方差偏移 $\log\sigma^2$ 均值。
5. **训练流模型**：`FlowModel(d=100, c_dim=100)`，8,000 步；每步 12 个扰动 × 48 对照/48 扰动细胞 → 匈牙利算法做 batch 内最优传输配对 → 回归速度 $x_1-x_0$。
6. **评测**：对每个测试扰动，输入**同一批 300 个对照细胞**，比较 6 种生成方式：

| 方法 | 做法 |
|---|---|
| No-change | 直接用对照细胞 |
| Mean-shift | 对照 + 训练扰动平均 Δ |
| PerturbFormer-shift | 对照 + PF 预测 Δ（只移动均值） |
| Borrowed-cells | 相似 5 个扰动的真实细胞（各自去均值后混合）+ PF 预测 Δ |
| **CFM (ours)** | 流匹配积分 20 步 |
| Oracle-shift | 对照 + **真实** Δ（参考上限） |

7. 指标：能量距离、RBF-MMD（median heuristic）、逐 PC 方差误差 $\lvert\log\sigma^2\rvert$；另有解码回基因空间后的伪批量指标。

**输出**：`results/{ds}/flow_fold{0..4}.pt`、`flow_singlecell_metrics.csv`、`flow_singlecell_summary.csv`、`flow_pca_capture.csv`（每折每扰动 Δ 落在潜空间的能量比例）、`flow_pseudobulk_summary.csv`、`flow_examples.npz`（案例细胞），开发模式带 `dev_` 前缀。

**关键数字**：CFM 能量距离 1.007 / 只平移 1.080 / 借用细胞 0.970 / Oracle 0.227；MMD 0.042 vs 0.051；方差误差 0.216 vs 0.260。

**坑**：`--dev` 模式故意把测试折替换为开发集，用于判断改进是否有效（`--var_cond` 就是这样被否掉的：1.090 vs 0.964）。

## 17 推理：`predict.py` 与 `VirtualCell` API


**内部流程**

1. `VirtualCell.load(models/k562, gmt=Hallmark)` → 重建 3 个模型 + 流模型 + 21k 基因先验 + 可靠性校准；

## 20 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `conda run -n vcp ...` 报 "unexpected error / 上传报告" | conda 24 自带 bug（与环境无关） | 直接用 `C:\Users\<user>\anaconda3\envs\vcp\python.exe`，或 `conda activate vcp` 后运行 |

| `UnicodeEncodeError: 'gbk' codec` | Windows 控制台默认 GBK，脚本 print 中文/特殊符号 | 设 `PYTHONIOENCODING=utf-8`；脚本内已尽量显式 `encoding="utf-8"` 写文件 |
| 内存不足 / 进程被杀 | GEARS + 流模型同时跑；或一次性读整个 h5ad | 二者不同时跑；用 `backed="r"` + 分块；关闭其他大程序 |
