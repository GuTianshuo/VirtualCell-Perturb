## 1 电梯稿（30 秒 / 3 分钟）

### 30 秒版

> 人类有 2 万个蛋白编码基因，Perturb-seq 实验一次只能测几百到几千个。我们做的是"虚拟细胞"：给定一个从未做过实验的基因，预测敲低它之后细胞的转录组会怎么变。
> 方法叫 PerturbFormer：把每个基因编码成 GO、蛋白互作、GPT 文本嵌入、数据驱动应答谱四种"知识 token"，然后让模型在**已经测过的扰动**里检索功能相似的基因，用它们的真实响应加权组合出预测；再加一个条件流匹配模型，把平均变化展开成每个细胞的反事实状态。
> 在 1,092 个未见基因上的交叉验证里，去系统偏差相关系数 0.480，是测量噪声上限的 59%，显著优于线性基线和已发表的 GEARS。

### 3 分钟版（= 汇报的压缩结构）

1. **问题（30 s）**：敲低未见基因的转录响应预测；两个陷阱——未见扰动泛化、系统性偏差（深度模型常常打不过"所有扰动的平均值"）。
2. **数据（30 s）**：Replogle 2022 K562 CRISPRi（1,092 扰动、16.3 万细胞、5,000 基因）+ Adamson 2016 做外部验证；四类先验知识。
3. **方法（60 s）**：知识 token → Transformer 融合 → **知识核交叉注意力**在已测扰动上检索 → 加权组合作预测 → 门控混入参数化分支；CRISPRi 敲低规则 + DEG 方向多任务损失；最后用**条件流匹配**把预测展开到单细胞。
4. **评测（30 s）**：按基因 5 折交叉验证、3 种划分、开发集隔离、基线同等调参、噪声天花板、配对检验 + Holm 校正、与 GEARS 公平重跑。
5. **结果（30 s）**：主表 + 三条结论 + 一项劣势（PerturbNet 方向准确率更高）+ 单细胞与外部验证的如实结论。
6. **解释（15 s）**：复合体/通路结构被保留；核糖体最可预测，GATA1 这类谱系主调控因子是明确的失败边界；每个预测都能给出"依据哪几个已测扰动、信哪个知识源"。

## 2 术语速查（老师随口提到时不能卡壳）

| 术语 | 中文/英文 | 一句话解释（本项目中的含义） |
|---|---|---|
| Perturb-seq | 扰动测序 | 把 CRISPR 扰动和单细胞 RNA 测序结合：一张表里同时读出"哪个基因被扰动"和"每个细胞的全转录组" |
| CRISPRi | CRISPR 干扰 | dCas9-KRAB 结合启动子抑制转录，**敲低**而非切断 DNA；本项目数据都是 CRISPRi |
| KD / KO | knockdown / knockout | 敲低（表达降低，通常不完全）/ 敲除（DNA 断裂，功能缺失） |
| pseudobulk | 伪批量 | 把同一个扰动的几十~几百个细胞按基因求平均，得到该扰动的"平均表达谱"；本项目监督模型在这一层工作 |
| Δ | delta，表达变化 | $\Delta_g = \bar x_{\text{pert}(g)} - \bar x_{\text{ctrl}}$，长度 5,000（基因数） |
| DEG | differentially expressed gene | 相对对照显著变化的基因；本项目用 Welch t + BH-FDR（α=0.05）判定 |
| unseen perturbation | 未见扰动 | 测试基因在训练时从未被扰动过，模型不能"背答案" |
| OOF | out-of-fold | 5 折交叉验证中每个基因恰好被留出一次，得到 1,092 个"未见基因"预测 |
| Systema 去偏 Pearson | de-biased Pearson | 先减去"训练扰动的平均响应"，再算相关；均值平移基线的该指标恒为 0 |
| 噪声天花板 | noise ceiling | 用同一扰动的细胞拆两半互测，估计"完美模型"能与实测值达到的相关上限 |
| Spearman-Brown | 斯皮尔曼-布朗校正 | 用半数据的信度 $r$ 推出全数据信度 $2r/(1+r)$ |
| kNN 基线 | k 近邻 | 在先验知识空间找最相似的 k 个已测基因，按相似度加权平均它们的响应 |
| 检索增强 | retrieval-augmented | 预测时显式"查表"：从已测扰动的响应库里取出相关条目再组合 |
| 交叉注意力 | cross-attention | Query=待预测基因，Key=已测基因，Value=已测基因的真实响应 |
| top-k 稀疏 | top-k sparsity | 注意力只保留相似度最高的 k=20 个记忆条目，其余置 −∞ |
| 门控 | gate | 用 softmax 权重把"检索分支"和"参数化分支"按基因自适应混合 |
| 知识核 | knowledge kernel | 注意力 logits 直接由先验知识相似度构成（初始 = 多源 kNN），只学修正量 |
| KD 规则 | knockdown rule | 领域先验：靶基因自身的表达必须下调（本项目按训练集中位残余比例压到 0） |
| 方向损失 | direction loss | 对显著 DEG 的符号做 soft-margin logistic 监督，与回归损失多任务联合训练 |
| source dropout | 知识源丢弃 | 训练时随机把一个知识源置为缺失，迫使模型不依赖单一先验 |
| CFM / OT-CFM | 条件流匹配 / 最优传输流匹配 | 学一个速度场 $v_\theta(x,t,c)$，把对照细胞分布连续输运到扰动后分布；mini-batch 内用匈牙利算法做最优配对 |
| FiLM | 特征线性调制 | 用条件向量生成每层的 scale/shift，把"扰动条件"注入网络 |
| 潜空间 / PCA | latent space | 5,000 基因 → 100 维主成分坐标；流模型在这个低维空间里工作 |
| 能量距离 / MMD | energy distance / maximum mean discrepancy | 两个细胞分布之间"离多远"的指标；越小越好 |
| bootstrap CI | 自助法置信区间 | 对 1,092 个基因有放回重采样 2,000 次得到指标区间 |
| Wilcoxon 符号秩 | paired Wilcoxon | 同一批基因上配对比较两个模型，不假设正态 |
| Holm 校正 | Holm correction | 多重比较校正；本项目对 18 次比较（3 划分 × 6 指标）做校正后计数基本不变 |
| 开发集 | dev split | 只在第 0 折训练扰动里划出的 87 个基因，用于模型/基线选参，不碰测试折 |

## 3 问题定义：到底预测什么

### 3.1 三个层次的输出（老师问"你的输出是什么"就答这个）

给定对照细胞状态 $x_0$ 与扰动基因 $g$：

| 层次 | 数学形式 | 本项目对应 |
|---|---|---|
| ① 伪批量平均变化 | $\hat\Delta_g=\mathbb E[x\mid g]-\mathbb E[x\mid\text{ctrl}]\in\mathbb R^{5000}$ | PerturbFormer（监督主模型） |
| ② 每个 DEG 的方向 | $\operatorname{sign}(\Delta_{g,i})\in\{+1,-1\}$ | 方向分类头 + 分层评测（§10.2） |
| ③ 单细胞分布与逐细胞反事实 | $p(x\mid g)$ 与映射 $x_0\mapsto x_1$ | 条件流匹配（OT-CFM） |

题目要求的"输入细胞 + 基因扰动 → 输出扰动后细胞状态"就是 ③；① 和 ② 是它的上游（流模型的**条件**正是 ① 的预测），也是评测里最容易量化、最能和文献比较的部分。

### 3.2 为什么"未见基因"是这个任务的本质

- 如果测试基因在训练时被扰动过，模型可以直接查表，任务退化成记忆——没有生物学价值。
- 实际应用场景（靶点发现、实验优先级排序）问的一定是**还没测过**的基因。
- 所以评测按**扰动基因**划分 5 折：每折 20% 的基因完全不出现在训练集中，1,092 个基因每个都当一次"未见基因"被预测（OOF）。

### 3.3 系统性偏差陷阱（这是本项目的"学术站位"）

近期两篇独立评测（Ahlmann-Eltze, Huber & Anders, *Nat Methods* 2025；Viñas Torné et al., *Nat Biotechnol* 2025 Systema）指出：许多深度扰动预测模型**并不优于"所有扰动的平均响应"**这个平凡基线。原因是大多数扰动共享一个系统性的"受扰动状态"（应激、细胞周期、生长抑制）。

本项目的应对，三件事都要说：

1. **报告 Systema 去偏 Pearson**：先减掉训练扰动的平均 Δ 再算相关，均值平移基线在该指标上恒为 0（§9.3 有证明）。
2. **报告识别排名**：用预测去匹配所有真实扰动，看真实扰动排第几（0=完美，0.5=随机）；均值平移恰好是 0.5。
3. **同时报告传统指标**，不选择性汇报：均值平移的全基因 Pearson 有 0.382、DEG 方向 0.643，看起来"不差"，但去偏相关为 0、识别排名为随机——这三个数字放在一起才是完整结论。

## 4 数据：从原始 h5ad 到伪批量

### 4.1 两个数据集与规模

| 数据集 | 来源 | 细胞系/技术 | 规模（本项目实测） | 用途 |
|---|---|---|---|---|
| Replogle 2022 K562 essential | *Cell* 2022，GEARS 预处理版（Dataverse 7458695） | K562，CRISPRi | 162,751 细胞 × 5,000 HVG；**1,092 个基因敲低**；10,691 个对照细胞；每个扰动的细胞数中位数 115（保留阈值 ≥15） | 主数据集：训练 + 5 折未见基因评测 |
| Adamson 2016 UPR | *Cell* 2016，GEARS 预处理版（Dataverse 6154417） | K562，CRISPRi | 68,603 细胞 × 5,060 基因；86 个扰动；24,263 对照 | 第二个数据集内评测 + 跨实验室外部验证 |

两数据集共有的基因 1,910 个；**在两个筛选中都被扰动**的基因 41 个——这 41 个用于构造"跨实验室可重复性上限"。

### 4.2 CRISPRi 是"敲低"不是"敲除"（★ 必问）

**答案**：题目说"敲除一个基因"，但公开的大规模 Perturb-seq 数据（包括本项目两个）用的是 CRISPRi：dCas9-KRAB 结合在启动子附近抑制转录，不切断 DNA，严格说是敲低。

**为什么可以回答题目的问题**（要给证据）：

- 在 412 个"靶基因本身也在测量范围内"的扰动中，靶基因 **100% 显著下调**，残余表达中位数接近 0（`results/interpretation/` 的 A 节）；
- **94.9%** 的扰动里靶基因是排名第一的差异基因；
- 从部署模型里取到的敲低残余比例 `kd_frac = 0.0`（训练集中位残差），说明在本数据的表达层面效果接近完全缺失。

**局限也要主动说**：真敲除（Cas9 切割）可能通过无义介导降解、截短蛋白产生不同效应；本项目的结论严格成立的范围是"CRISPRi 敲低、K562、单基因"。

### 4.3 为什么在伪批量上做监督学习，而不是直接在单细胞上

1. 单细胞数据 90% 以上的变异是**技术噪声**（dropout、文库大小），直接回归单细胞会让模型学噪声；
2. 我们的目标是"扰动导致的系统性变化"，这正是伪批量均值的定义；
3. 单细胞信息不丢——它被保留给流模型（潜空间里学分布形状、方差、亚群结构），两条路线互补；
4. 也让结果能和文献（GEARS、线性基线、Systema）在同一个指标定义下比较。

### 4.4 预处理与统计细节（`scripts/01_preprocess.py`）

- **表达值**：直接用 GEARS 发布的 log-normalized（log1p(size-factor 归一化))，不再二次变换，保证可比。
- **分块稀疏聚合**：160k × 5k 的矩阵不 densify；按 20,000 行一块，用稀疏指示矩阵一次算出所有扰动的均值/方差（峰值内存约 3.8 GB，4 核 CPU 可跑）。
- **差异检验**：每个扰动 vs 对照做 Welch t 检验（不假设等方差，Welch-Satterthwaite 自由度），然后按行做 Benjamini-Hochberg FDR。
  - 老师可能问的坑：为什么不用普通 t 检验？——每个扰动的细胞数差异很大（几十到几千），等方差假设不成立。
  - 我们踩过的坑（已修，可主动讲）：自由度分母里误加绝对 ε 会让低表达基因的 df 塌缩到 1、p 值被高估，现已与 `scipy.stats.ttest_ind(equal_var=False)` 逐位一致，并留了回归单元测试。
- **DEG 定义**：Top-k 按 |t| 排序；"显著 DEG" = |t| 排名在前 k **且** FDR<0.05。
- **单细胞潜空间**：在分层抽样的细胞上拟合 100 维 PCA（对照 5,000 个 + 每个扰动 40 个），把所有细胞投影为 100 维坐标。评测时**每折只用对照 + 训练扰动的细胞重新拟合**（防泄露，见 §9.6）。

### 4.5 100 维 PCA 够用吗（老师常追问）

- 100 维 PCA 只解释单细胞总方差的 **15.5%**，其余主要是单细胞测序采样噪声；
- 但对每一折未参与拟合的扰动，其**平均响应 Δ 有 61%（训练扰动 62%）的能量落在该潜空间内**（中位数）——也就是说"扰动效应"这个信号主体被保住了，剩下的是噪声；
- 解码时把 Δ 在 PCA 正交补上的部分**加回去**，所以靶基因自身被敲低这种"低维看不见"的效应不会丢（§8.4）。

## 5 扰动编码：怎么把"基因 g"变成向量

核心矛盾：模型要对**没见过**的基因做预测，所以扰动编码不能是"one-hot 的基因编号"，必须来自**与表达无关的先验知识**，让功能相似的基因在向量空间里靠近。

### 5.1 四种 token 及为什么这么设计

| 知识源 | 维度 | 构造方式 | 为什么这样构造 | 覆盖率（1,137 个扰动基因） |
|---|---|---|---|---|
| GO | 128 | 基因 × GO 术语的 0/1 矩阵 → **TF-IDF** → 截断 SVD | TF-IDF 压掉"几乎所有基因都有的通用术语"（如 protein binding）；SVD 得到稠密低维表示；余弦相似度 ≈ 功能相似 | 99.6% |
| STRING PPI | 128 | v12 人类蛋白互作网络（combined score ≥ 700）→ 度归一化邻接 $P$ → **$P+P^2$** → SVD | $P$ 一阶邻居 + $P^2$ 二阶邻居：既编码"直接互作"，也编码"同复合体/同通路但不相邻"；归一化避免 hub 蛋白主导 | 97.6% |
| GenePT | 128 | GPT-3.5 嵌入的 NCBI 基因功能摘要 → PCA 降到 128 维 | 这是"生物医学语言模型"的先验：只读文献摘要就能知道基因功能，能捕捉 GO/PPI 里没有的书面语义 | 99.5% |
| 应答谱 | 64 | 训练响应矩阵 $Y_{\text{train}}$（扰动 × 基因）做 SVD，取基因侧奇异向量 | 纯数据驱动：基因 g 在"被扰动时的表现"上的签名；**只在该基因被测量时可用**，每折只用训练扰动计算（防泄露） | 37.7% |

**为什么必须多源**：消融显示三种外部知识互补——去掉 GO −0.029、GenePT −0.024、PPI −0.020（去偏 Pearson）；单一先验的效果 GO 0.42 > PPI 0.37 > GenePT 0.33 ≫ 应答谱 0.08。数据驱动的应答谱在"未见基因"上几乎不能泛化，这本身就是一个结论：**未见基因泛化只能靠外部知识，不能靠数据自监督**。

### 5.2 缺失知识怎么处理（老师可能问"STRING 里没有这个基因怎么办"）

- 每个知识源都有一个**可学习的"缺失 token"**：$\text{token}_s=m_s\cdot h_s+(1-m_s)\cdot\text{missing}_s+e_s$，其中 $m_s\in\{0,1\}$ 是该源是否可用。
- 训练时做 **source dropout**：随机把某一个知识源在整批样本里置为缺失（概率 25%），迫使模型在缺先验时也能工作。
- 检索时的相似度按**可用性归一化**：$\sum_s w_{hs}m_s(i)m_s(j)\cos(\cdot)/\sum_s w_{hs}m_s(i)m_s(j)$，两个基因都必须有该源才计入，所以缺失不会把相似度"拉低"成 0。

### 5.3 全基因组覆盖（现场演示的价值所在）

`models/k562/gene_universe_embeddings.npz` 覆盖 **21,449 个基因**：GO 88.0%、STRING 75.5%、GenePT 91.2%。所以用户可以查询任何有先验知识的基因（例如筛选中从未扰动过的 MYC、TP53），只有"三源全缺"的基因才会被拒绝（`predict.py` 会直接报错说明原因）。

## 6 基线：先证明"我不是在和稻草人比"

### 6.1 五个基线（每个都要能写出公式）

| 基线 | 公式 / 做法 | 为什么必须有 |
|---|---|---|
| No-change | $\hat\Delta=0$ | 最低参照，检验指标定义是否正常（应得 0 分） |
| Mean-shift | $\hat\Delta=\frac1{P}\sum_{j\in\text{train}}\Delta_j$（与查询基因无关） | 文献中最强的"平凡基线"；均值平移的全基因 Pearson 有 0.382，是很多深度模型的水平 |
| Linear (Ahlmann-Eltze 2025) | $\Delta\approx b+G\,W p$：$G$=训练响应的前 k 个主方向（k=32），$p$=扰动嵌入，$W$ 用双岭回归闭式解 | 该论文的核心结论就是"深度模型打不过线性基线"；必须证明我们的模型能打过**调参后**的它 |
| kNN | 在先验空间中取余弦相似度最高的 10 个已测基因，$w\propto e^{s/\tau}$（τ=0.1）加权平均其响应 | 与 PerturbFormer 思想最接近的强基线；是检验"学习到底有没有额外价值"的关键对照 |
| PerturbNet | 同样的知识 token → Transformer 融合 → MLP 解码（无检索） | 标准监督深度模型，检验"检索"这一设计本身的价值（去偏 Pearson 0.443 vs 0.480） |
| GEARS（已发表） | Roohani et al. 2024 官方实现，GO + 共表达图 GNN | 数据的发布者、该任务最常被引用的方法；用官方代码在同一划分上重训 |

### 6.2 CRISPRi 敲低规则（KD rule）——最简单的领域知识，贡献最大

$$\hat\Delta_{\text{target}}=\bar x_{\text{ctrl,target}}\cdot(\text{kd\_frac}-1),\qquad \text{kd\_frac}=\text{median}_{j\in\text{train}}\frac{\bar x_{\text{pert}(j),j}}{\bar x_{\text{ctrl},j}}$$

- 本项目训出的 `kd_frac = 0.0`（训练集里靶基因残余表达的中位数是 0），于是规则等价于"把靶基因压到 0"；
- 效果：Top-20 DEG Pearson **+0.072**、去偏 Pearson +0.011；
- 为什么这么有效：靶基因在 94.9% 的扰动中是排名第一的 DEG，而"未见基因"的靶基因表达在检索里是查不到的（它自己没被测过），只能靠规则补；
- 老师可能问"这是不是作弊"：不是——它是**领域先验**（CRISPRi 的下调机制），不是标签；而且消融里明确量化了它的贡献，也明确说明"去掉它模型仍然显著优于基线"。

### 6.3 基线同等调参（这是最容易被质疑"你不公平"的地方）

- PerturbFormer 的超参数在开发集上看过 → 为公平，kNN 与 Linear 也在**同一个开发集**上网格搜索（kNN：k∈{3,5,10,20,40}×τ∈{0.02…0.5}；线性：k∈{8…128}×λ∈{0.01…10}，按三项 Pearson 平均选）；
- 选中：kNN k=20、τ=0.1；Linear k=128、λ=1.0；
- 调参后基线的 3 划分平均：Linear 去偏 0.452、kNN 0.477、PerturbFormer 0.479 —— 相关性上 **kNN 与 PF 基本持平**（差 ≤0.004），PF 稳定优势集中在 DEG 方向（+0.010）、Top-20 DEG 重合（+0.014）、识别排名（−0.013）。
- ⚠️ 这一条要主动讲：**主动承认相关性上只是持平**，比被老师问出来强得多。

## 7 PerturbFormer 工作原理（核心，必须能画出来讲清楚）

### 7.1 一句话版本

> 把待预测基因在四种先验知识里的"相似度"直接当作注意力分数，去**加权组合已经测过的扰动的真实响应**；同时用一个低秩参数化分支补足"没有相似基因可借"的情况，两者按基因自适应门控混合。

### 7.2 计算流程（7 步，可在白板上画）

**输入**：查询基因 $i$ 的 4 个知识 token；记忆库 = 训练集中所有已测基因 $j$ 的 4 个知识 token 及其真实响应 $\Delta_j\in\mathbb R^{5000}$。

1. **token 化**：每个源 $s$ 的特征 $e_s$ 经 `Linear→LayerNorm→GELU→Dropout` 投到 $d=128$，按可用性 $m_s$ 与"缺失 token"混合，再加源嵌入 $e_s$。
2. **融合编码**：拼上 CLS token，过 2 层 Transformer encoder（4 头，norm_first），取 CLS 输出 $h_i$。
3. **知识核相似度**（这是与普通 attention 的唯一区别）：
   $$\text{sim}(i,j)=\frac{\sum_s w_{hs}(i)\,m_s(i)m_s(j)\cos\!\big(A_s e_s(i),A_s e_s(j)\big)}{\sum_s w_{hs}(i)\,m_s(i)m_s(j)},\qquad \text{logit}_{h}(i,j)=\frac{\text{sim}_h(i,j)}{\tau_h}$$
   - $A_s$：每个源一个可学习线性映射，**初始化为单位阵**；
   - $w_{hs}(i)=\text{softplus}(\cdot)$：查询相关的源权重，初始化为 1；
   - $\tau_h$：每个头的温度（初始 0.1 / 0.05）。
4. **top-k 稀疏**：只保留 logit 最高的 $k=20$ 个记忆条目，其余 −∞，再 softmax。
5. **检索输出**：$\text{retr}_h(i)=\sum_j a_{h}(i,j)\,\Delta_j\in\mathbb R^{5000}$（多头各一份）。
6. **参数化分支**：$\text{param}(i)=\mu+\text{dec}(h_i)B^\top$，$\mu$=训练响应均值，$B$=训练响应 PCA 前 32 个主方向，$\text{dec}$：128→256→32。
7. **门控混合**：$g=\text{softmax}(\text{gate}(h_i))\in\mathbb R^{H+1}$，
   $$\hat\Delta_i=\sum_h g_h\,\text{retr}_h(i)+g_{H+1}\,\text{param}(i)$$
   最后在模型外部施加 KD 规则覆盖靶基因那一维。

### 7.3 为什么这样设计（每一条都有消融数字支撑）

| 设计 | 理由 | 证据 |
|---|---|---|
| 注意力 logits = 先验相似度（知识核） | 只有约 870 个训练扰动，从零学一个注意力容易过拟合；以"多源 kNN"为起点、只学修正量，是强归纳偏置 | 换成自由注意力（free attention）去偏 −0.021 |
| $A_s$ 初始化单位阵 | 初始化时模型**精确等价于多源余弦 kNN**，训练只会让它变好；这是"至少不差于 kNN"的结构性保证 | 同上 |
| 查询相关源权重 $w_{hs}(i)$ | 不同基因该信不同的知识：Mediator 类更信 PPI（0.41），翻译起始因子更信 GenePT（0.31），核糖体三源平均 | §10.5；图 `fig_interp_F_sources.png` |
| top-k=20 稀疏 | 记忆库 870 个条目，k 太小噪声大、k 太大混入不相似扰动；稀疏也让"依据哪几个扰动"可读 | 去掉 top-k：去偏 −0.003、方向 −0.001、识别排名变差 |
| 多头 + 不同温度 | 不同头学不同"粗细粒度"的邻居（类似多尺度核） | 消融中自由注意力下降说明结构有用 |
| 参数化低秩分支 | 有些基因在知识空间里没有近邻（GATA1），只能退回"平均响应 + 低秩修正" | 门控权重在演示输出里可见 |
| 门控 bias 初始 $[1,1,-1]$ | 初始更信检索，参数分支作为兜底 | — |

### 7.4 损失函数（多任务：回归 + 方向）

$$\mathcal L=\underbrace{\frac{\sum_g W_{ig}(\hat\Delta_{ig}-\Delta_{ig})^2}{\sum_g W_{ig}}}_{\text{DE 加权 MSE}}+\lambda_{\text{dir}}\cdot0.01\cdot\underbrace{\frac{\sum_{g\in\text{DEG}}\text{softplus}\!\big(-S_{ig}\hat\Delta_{ig}/0.05\big)}{|\text{DEG}|}}_{\text{方向 soft-margin 损失}}$$

- $W=1+5\cdot[\text{rank}<20]+2\cdot[\text{rank}<100]$：Top-20 DEG 权重 6、Top-100 权重 3、其余 1 → 模型把容量放在真正有生物学意义的基因上；
- $S_{ig}=\operatorname{sign}(\Delta_{ig})$，仅在 |t| 排名前 100 且 FDR<0.05 的基因上有定义（其余为 0，不计损失）；
- 除以 0.05 等价于 margin=0.05 的 soft-margin logistic，把梯度尺度放大 20 倍，所以 $\lambda_{\text{dir}}=0.5$ 时该项**实际影响与 MSE 同量级**，不能理解成"权重 0.5%";
- 消融：去掉方向损失 → 方向准确率 0.833→0.827，去偏 −0.003（作用是"小幅但一致"）。

### 7.5 训练配置（老师问"你怎么训的"）

| 项 | 值 |
|---|---|
| 优化器 | AdamW，lr=1e-3，weight decay=1e-3 |
| batch | 64 个扰动 |
| 最大 epoch | 300，早停耐心 40 |
| 早停准则 | 验证集 Top-20 DE 加权 Pearson − 10×MSE（只用训练扰动内部的 10% 验证集） |
| 集成 | 3 个随机种子，预测取平均 |
| 参数量 | **585,909**（约 0.59 M，checkpoint 2.3 MB） |
| 训练成本 | 单次训练（约 100 秒）级别：4 核 CPU 下 5 折 × 3 集成约 25 分钟；主评测全部 36 个模型/消融约 84 分钟 |
| 正则 | 知识源 dropout（25%）、token dropout 0.1、早停 |

### 7.6 为什么不做更大的模型（★ 高频质疑）

标准回答三层：

1. **任务难度不在容量**：训练数据只有约 870 个扰动 × 5,000 基因，而扰动预测的信号主要来自"功能相似的基因有相似响应"，这是一个**检索/核方法**问题，不是表示学习问题；
2. **文献证据**：Ahlmann-Eltze 2025 的独立评测显示，在这类数据上深度模型普遍不优于线性基线；我们把容量花在"结构化归纳偏置"上，消融显示自由注意力反而更差；
3. **可复现与算力**：全流程 CPU 4 小时可复现；同时我们用 3 个划分 × 3 种子 × 18 项指标 + Holm 校正来保证结论不是偶然，比把模型做大更值得投入。

## 8 高级版本：条件流匹配（生成单细胞）

### 8.1 为什么"只预测均值"不够

敲低一个基因不只改变平均值，还改变**方差、分布形状、亚群比例**。例：MED12 敲低后真实细胞在潜空间呈双峰，均值平移只能给出一个高斯团。题目要"输出扰动后细胞状态"，逐细胞的反事实映射必须由生成模型给。

### 8.2 数学（能写出这四行就够）

在 100 维 PCA 潜空间：

1. 配对：每个扰动内，batch 里 48 个对照细胞与 48 个扰动细胞按平方欧氏距离做**匈牙利算法精确最优传输配对**（Tong et al. 2024 的 mini-batch OT-CFM）；
2. 插值路径：$x_t=(1-t)x_0+t\,x_1+\sigma\epsilon,\quad t\sim U(0,1),\ \sigma=0.05$；
3. 回归目标速度：$u=x_1-x_0$；
4. 损失：$\mathcal L=\big\|v_\theta(x_t,t,c)-\ (x_1-x_0)\big\|^2$。

采样时从对照细胞 $x_0$ 出发，**中点法 20 步**积分 ODE $\mathrm dx/\mathrm dt=v_\theta(x,t,c)$ 到 $t=1$。

### 8.3 条件 $c$ 怎么来的（防泄露的关键）

$$c=\hat\Delta_g\,B_{\text{PCA}}^\top\in\mathbb R^{100}$$

- 对**测试基因**：用 PerturbFormer 的正常预测（该基因本来就没被测过，天然无泄露）；
- 对**训练基因**：必须用 **leave-self-out** 预测——把它自己从记忆库里剔除后再预测（`predict_perturbformer_loo`）。否则条件里含"它自己的真实响应"，训练和测试的条件分布就不一致了（这是本项目第二轮验收修复的要点之一）。

### 8.4 解码回基因空间（细节，体现严谨性）

$$x=\bar x_{\text{ctrl}}+zB+\underbrace{\big[\Delta-(\Delta B^\top)B\big]}_{\text{PCA 正交补的均值部分}}$$

流模型只负责 PCA 子空间内的分布；子空间之外的均值效应（典型例子：靶基因自身被压到 0，在 100 维里几乎看不见）由 PerturbFormer 的 Δ 补回。这样生成细胞的**平均值与伪批量预测一致**（解码后全基因 Pearson 0.556 vs 0.567）。

### 8.5 网络与训练

- 网络：`x` 与 `c` 拼接 → Linear(256)；时间 $t$ 用 32 维 sin/cos 嵌入；条件经 MLP；**3 个 FiLM 残差块**（LayerNorm 无仿射 + FiLM 生成 scale/shift，初始化全 0 → 初始为恒等映射；残差 FFN 用 SiLU）；输出层零初始化（初始速度场为 0，训练稳定）；
- 训练：8,000 步，每步 12 个扰动 × 48 细胞，AdamW lr=1e-3 + OneCycle（5% warmup）、wd=1e-4、梯度裁剪 1.0；
- 参数量 1,427,044（1.4 M，checkpoint 5.7 MB）；单折训练约 8 分钟（CPU）。

### 8.6 结果与"失败"的诚实结论（★ 老师可能赞赏也可能追问）

- 相对"只平移 PerturbFormer 预测的均值"：能量距离 **−7%**（1.080→1.007，p=9e-35）、MMD **−17%**、方差误差 **−17%**（p=6e-33）；
- 但相对一个**免训练**的强基线"借用最相似 5 个已测扰动的真实细胞"（0.970）：**持平**（0.970 vs 1.007，逐扰动 p=0.6，不显著）；
- 流模型不可替代的价值：给出**逐细胞**映射（同一个输入细胞 → 它自己的反事实状态），借用细胞只能给群体；
- 一次失败的改进也如实写进报告：把"相似扰动的方差谱"也作为条件（`--var_cond`），开发集上反而变差（1.090 vs 0.964），因此**没有采用**；
- Oracle 平移（用真实均值）能量距离只有 0.227 → 说明单细胞层面的主要误差来自**均值预测**，而不是分布形状。这条对"下一步该做什么"很有说服力。

## 9 评测设计：为什么我的数字是可信的

老师在"实验严谨性"上扣分最多的地方通常只有三类：数据泄露、基线太弱、只报好看的指标。本节的每一条都对应一个防守点。

### 9.1 未见基因 5 折交叉验证

- 按**扰动基因**随机划分 5 折（不是按细胞），每折 20% 基因完全不出现在训练中；
- 1,092 个基因每个恰好被预测一次（OOF），所以主表是"1,092 个未见基因"的平均，而不是某一折；
- 划分用 3 个随机种子（0/1/2）重复，检验结论对划分的依赖（§9.5）。

### 9.2 开发集隔离与"选择偏差"的诚实说明

- 模型设计与超参数只在**开发集**上比较：第 0 折的训练扰动里再划出 10% 内部验证集（87 个基因）；
- 但必须承认：开发集基因在**第 1–4 折**里是测试基因。因此严格说，只有**第 0 折的 219 个测试基因**从未参与任何设计选择；
- 报告第 8 节单独报告第 0 折：PerturbFormer 相对 kNN 的优势在这一折**更大**（去偏 +0.012 vs 第 1–4 折 +0.005），没有迹象表明设计过程抬高了结果；
- 开发集扫描的极差很小（Top-20 DEG Pearson 0.007、去偏 0.015，同配置不同种子 sd≈0.004），且最终用的是默认配置，并未按开发集最优挑选。

### 9.3 指标定义（逐个能说清楚）

| 指标 | 定义 | 均值平移的值 | 说明 |
|---|---|---|---|
| Pearson Δ（全部/ Top-20 DEG） | 每个扰动算 pred Δ 与 true Δ 的 Pearson，再对扰动平均 | 0.382 / 0.464 | 传统指标，含系统性偏差 |
| Top-20 DEG MSE | 只在 Top-20 DE 基因上算 | — | GEARS 标准 |
| **去偏 Pearson** | 先把 pred 与 true 各自减去 $\bar\Delta_{\text{train}}$ 再算相关 | **0** | 只奖励扰动特异信号；均值平移恒为 0（见下） |
| **DEG 方向准确率** | Top-20 / Top-100 中 FDR<0.05 的基因，sign 是否一致 | 0.643 | 题目明确要求的任务 |
| Top-20 DEG 重合率 | 预测 |Δ|/对照标准差 的 Top-20 ∩ 真实 Top-20 | 0.091 | 衡量"找得对不对" |
| **识别排名** | 用预测匹配全部测试扰动，真实扰动的归一化排名 | 0.500 | 0=完美，0.5=随机 |
| 能量距离 / MMD / 方差误差 | 生成细胞分布 vs 真实分布 | — | 单细胞层面 |

**为什么均值平移的去偏 Pearson 恰好是 0**（可当场推导）：去偏算子把两者都减去同一个参考向量 $\bar\Delta_{\text{train}}$，而均值平移的预测就是 $\bar\Delta_{\text{train}}$，于是 pred−ref ≡ 0，相关系数定义为 0。这个"恒等式"就是该指标能识别平凡基线的原因。

### 9.4 噪声天花板：0.813 这个上限怎么来的

1. 把每个扰动（以及对照）的细胞**随机拆成两半** A/B；
2. 用 A 半测出的 Δ 当"预测"，去评估对 B 半的 Δ（`04_noise_ceiling.py`）；
3. 得到半数据信度 $r$（本项目全基因 0.544、Top-20 DEG 0.817、去偏 0.526）；
4. **Spearman-Brown**：全数据的信度 $=2r/(1+r)$；
5. 完美预测器与"全数据实测估计"的相关上限 $=\sqrt{2r/(1+r)}$，对扰动取平均 → **0.813 / 0.900 / 0.808**。

**怎么讲**：0.480/0.813 ≈ 59% —— 这不是"模型只做到了 48%"，而是"在测量噪声面前，可达到的上限本来就只有 0.81"。

### 9.5 统计检验

- 每个模型每个扰动一个指标值 → **配对 Wilcoxon 符号秩检验**（不假设正态）；
- **95% bootstrap 置信区间**：对 1,092 个扰动有放回重采样；
- **多重比较**：3 种划分 × 6 项指标 = 18 次比较，对每一组对照做 **Holm 校正**。
  - 对未调参 kNN：未校正 15 胜/1 负/2 平 → Holm 后 14/1/3（划分 0 的方向 +0.005，p_holm=0.083 失去显著）；
  - 对**调参后** kNN：15/2/1，Holm 后计数不变；
  - 对调参后 Linear：18 次全部显著更好。

### 9.6 防泄露清单（★ 老师最喜欢查这个，逐条答）

| 潜在泄露点 | 本项目做法 |
|---|---|
| 单细胞 PCA 用了测试扰动的细胞 | 每折只用对照 + 训练扰动细胞重新拟合（第二轮修复；修复后结论不变，幅度 8%→7%） |
| 应答谱嵌入用了测试扰动 | 每折只用训练扰动计算（有单元测试：改测试扰动的响应，嵌入不变） |
| 流模型条件含自身真实响应 | 训练扰动用 leave-self-out 预测做条件 |
| 先验知识含表达信息 | GO/PPI/GenePT 只用注释、网络、文本，不含任何表达响应，因此在全基因上拟合不构成泄露 |
| 超参数看了测试集 | 只在开发集（第 0 折内部验证）上选参，并单独报告第 0 折 |
| 划分随机性 | 3 个种子重复 |
| 基线太弱 | 基线同等调参 + GEARS 公平重跑 |

### 9.7 外部验证（跨实验室）

- 训练：Replogle，**剔除全部 86 个 Adamson 靶基因**（保证"未见基因"）；
- 测试：Adamson 的 86 个扰动，在 1,910 个共有基因上评估；
- 上限：对 41 个"两个筛选都测过"的基因，用 **Replogle 实测响应**去预测 Adamson，作为跨实验室可重复性上限；
- 结果：PerturbFormer 全基因 0.394，达到上限 0.458 的 86%；Top-20 DEG 0.492/0.624 = 79%；去偏 0.265/0.398 = 67%；
- 如实说明：在外部数据上 **kNN 略优于 PF**（Top-20 0.506 vs 0.492，去偏 0.277 vs 0.265）——可学习模型在训练分布内的小优势没有保持到跨实验室场景。

### 10.2 DEG 方向（题目直接要求的任务）

### 10.3 效应强度分层

### 10.4 第二个数据集（Adamson 数据集内评测）

## 11 题库：老师可能问的 76 个问题

> ★ = 高概率；每题给"答案要点"。答的时候先给结论，再给数字，最后主动补一句局限——比被追问强。

### A 选题与动机（5 题）

**A1 ★ 这个问题的科学价值是什么？**
人类约 2 万个蛋白编码基因，组合扰动约 2 亿种，再乘细胞类型与剂量，实验无法穷举。Perturb-seq 单次全基因组筛选要几十万到上百万细胞、成本极高。虚拟细胞的目标是"在计算机里先筛选、把实验预算花在最有希望的扰动上"。应用场景：靶点发现、遗传相互作用预测、脱靶/毒性预警、实验设计优化。参考文献：Bunne et al., *Cell* 2024；CZI/Arc 的 Virtual Cell Challenge 2025。

**A2 "虚拟细胞"目前的研究现状？**
两类路线：一是**大规模细胞基础模型**（scGPT、Geneformer 等，用千万级细胞图集预训练）；二是**扰动响应预测**（GEARS、线性基线、Systema 等）。独立评测（Ahlmann-Eltze 2025）发现后者中深度模型普遍不优于线性基线，说明"未见扰动泛化"远未解决。本项目属于第二类，并明确把"能不能打过简单基线"作为首要检验。

**A3 你的任务和"基因功能预测"有什么区别？**
基因功能预测（如 GO 注释预测）回答"这个基因做什么"；本项目回答"扰动它以后，5000 个基因的表达各自变多少、往哪个方向变"，是**定量的、全转录组层面的因果响应预测**，要靠功能相似性做迁移但不能停在功能标签上。

**A4 ★ 为什么强调"未见基因"？**
如果测试基因测过，模型可以查表背答案，任务没有价值。真实应用问的必然是没测过的基因。所以评测按基因划分 5 折，每个基因都当一次未见基因，靠 GO/PPI/语言模型这些与表达无关的先验做迁移。

**A5 为什么选 K562 必需基因筛选？**
Replogle 2022 是迄今规模最大的 Perturb-seq 之一（1,092 个必需基因、16 万细胞），有官方预处理版（GEARS 发布）、被广泛用作基准，能与 GEARS/线性基线/Systema 在完全相同的设定下比较。"必需基因"意味着敲低后细胞仍有可测的转录响应（不是全死光），同时这类基因功能注释充分、适合检验"知识迁移"。

### B 数据（8 题）

**B1 ★ 为什么用 CRISPRi 数据回答"敲除"？**
CRISPRi 是 dCas9-KRAB 抑制转录、不切 DNA，严格说是敲低。但本数据中：412 个靶基因被测的扰动里靶基因 100% 显著下调、残余中位数接近 0，94.9% 的扰动靶基因是第一 DEG，部署模型的敲低残余比例取到 0——表达层面效果接近缺失。局限：真敲除可能有 NMD/截短蛋白等不同效应，本项目结论的适用范围是 CRISPRi + K562 + 单基因。

**B2 为什么两个数据集规模差这么多？**
Replogle 是全基因组筛选（每个扰动中位 115 个细胞），Adamson 聚焦内质网应激（86 个扰动，每个约 500 细胞）。前者覆盖广、噪声大；后者覆盖窄、信度高（噪声上限 0.99）。正好互补：一个考验泛化，一个检验信度高的条件下方法是否仍然成立。

**B3 ★ 为什么在伪批量上做，而不是单细胞？**
单细胞 90% 以上变异是技术噪声；扰动效应是群体层面的系统性变化，伪批量均值正是它的定义；单细胞信息保留给流模型。伪批量也让指标能与文献定义完全对齐（GEARS/Systema 都在这一层评测）。

**B4 为什么用 Welch t 检验而不是普通 t 检验？**
每个扰动的细胞数差异很大（几十到几千），等方差假设不成立。Welch t 不假设等方差、用 Welch-Satterthwaite 自由度。我们踩过一个坑：自由度分母误加绝对 ε 会让低表达基因 df 塌缩、p 值虚高，已修正并与 scipy 逐位对齐，留了回归测试。

**B5 为什么用 BH-FDR 而不是 Bonferroni？**
每个扰动要对 5,000 个基因做检验，Bonferroni 过保守会让 DE 基因数量骤减、Top-20 几乎全是极强效应基因。BH 控制 FDR 在相同水平下更符合"筛选候选基因"的用途（这也是 scPerturb/GEARS 的通行做法）。FDR 阈值取 0.05。

**B6 为什么只保留 ≥15 个细胞的扰动？**
细胞太少时均值方差不可靠（方差估计的自由度不足，噪声上限极低），会让评测变成"预测噪声"。保留 1,092 个基因后，每个扰动的细胞数中位数为 115。

**B7 表达值怎么归一化的？**
直接用 GEARS 发布的 log-normalized（log1p(size-factor 归一化)），不再二次处理，保证与文献可比；Δ 就是 log 空间的均值差，可解读为 log fold-change 的近似。

**B8 数据里有没有"细胞死了"的影响？**
必需基因敲低会抑制生长，这会带来一个共性的"受扰动状态"（应激、生长停滞），正是系统性偏差的来源。我们不试图消除它（它也是真实生物学），而是用去偏指标把它与"扰动特异信号"分开评估，并用识别排名检验模型是否真的区分了不同扰动。

### C 表征与先验（7 题）

**C1 ★ control / perturbed 细胞是怎么表征的？**
两层：① 单细胞层——100 维 PCA 潜空间（在对照 + 训练扰动细胞上拟合），三类复合体敲低后的细胞平均偏离对照 0.73–0.87 个对照标准差，方向各不相同；② 扰动层——伪批量响应 Δ 作为"扰动表征"，同类复合体基因的 10 个最近邻里 78% 是同类（随机打乱仅 5%），这是"借鉴相似已测基因"能成立的生物学基础。

**C2 ★ 扰动怎么编码成向量？为什么不用 one-hot？**
四种知识 token：GO（TF-IDF+SVD 128）、STRING PPI（$P+P^2$ 谱嵌入 128）、GenePT（GPT 文本嵌入 PCA 128）、应答谱（训练响应 SVD 64）。one-hot 对未见基因毫无信息；先验编码让功能相似的基因在向量空间靠近，模型才能"借"相似基因的响应。缺失的知识用可学习缺失 token + source dropout 处理。

**C3 为什么 GO 用 TF-IDF 而不是直接二值矩阵？**
几乎所有基因都带有"protein binding"这类通用术语，二值矩阵的相似度会被这些高频词主导。TF-IDF 压低通用术语、抬高特异术语，再 SVD 得到稠密低维表示，余弦相似度才接近"功能相似"。

**C4 为什么 PPI 用 $P+P^2$？**
$P$ 是一阶邻居（直接互作），$P^2$ 是二阶邻居（同复合体/同通路但不相邻，例如同一个 Mediator 模块的两个亚基可能不直接互作）。加上二阶能显著提高同类召回；度归一化（$D^{-1/2}AD^{-1/2}$）避免 hub 蛋白主导所有相似度。

**C5 GenePT 算不算"大模型先验"？**
算。GenePT 把 NCBI 基因功能摘要用 GPT-3.5 嵌入，本质是"语言模型读文献得到的基因表示"。消融显示它有用（去掉 −0.024），且对翻译起始因子这类注释零散的类别特别重要（权重 0.31）。它不是 scRNA 基础模型，但同样带来"文本知识"。

**C6 应答谱（response embedding）为什么要单列？它会不会泄露？**
它是纯数据驱动的：基因 g 在"被扰动时"的响应签名（训练响应矩阵的基因侧 SVD）。只有 37.7% 的扰动基因被测量到，且它**不能泛化到未见基因**（单源去偏只有 0.08），所以价值有限。防泄露：每折只用训练扰动计算，并有单元测试保证"改测试扰动的响应不改变嵌入"。

**C7 先验知识本身有偏吗？**
有，这是要在讨论里主动承认的局限：研究充分的基因注释更多、预测更准（"研究偏倚"）；GO/PPI 对膜蛋白、转录因子覆盖不均；GenePT 依赖摘要质量。这也是为什么我们报告"可靠性评级"——先验离已知基因越远，预测越不可靠。

### D 模型原理（12 题）

**D1 ★ 用一句话解释 PerturbFormer。**
在"已测扰动记忆库"上做知识核交叉注意力：用多源先验相似度当注意力分数，加权组合已测扰动的真实响应；再门控混入一个低秩参数化分支；外加 CRISPRi 敲低规则与 DEG 方向多任务损失。

**D2 ★ 和标准 Transformer attention 的区别？**
标准 attention 的 logits 由可学习投影的点积给出、从零学；我们的 logits **直接是先验知识余弦相似度的加权平均**，$A_s$ 初始化为单位阵、源权重初始化为 1，所以初始化时模型精确等于"多源 kNN"，训练只学修正。消融：换成自由注意力去偏 −0.021。

**D3 为什么要"初始化成 kNN"这个技巧？**
训练样本只有约 870 个扰动，而输出维度 5,000，参数量稍大就容易过拟合到训练基因的响应模式。以强先验为起点，模型只需学"如何偏离 kNN"，等价于给了一个很强的归纳偏置与结构性下界。

**D4 检索分支和参数化分支怎么混合？**
门控 $\text{softmax}(\text{gate}(h_i))\in\mathbb R^{H+1}$（H=2 个头 + 1 个参数分支），bias 初始化为 $[1,1,-1]$ 使初始更信检索。混合后的输出再过 KD 规则。

**D5 top-k=20 的依据？为什么不是 5 或 50？**
记忆库 870 个条目，k 太小（如 5）邻居噪声大且容错差，k 太大混入不相似扰动、注意力被稀释。20 是经验选择，去掉 top-k（全 softmax）去偏 −0.003、方向 −0.001、识别排名变差，说明稀疏有正面作用。这个 k 没有在测试集上调，属于默认配置。

**D6 为什么用多任务方向损失？**
回归损失只约束幅度，信号弱的基因符号容易被"平均化"。方向损失直接对显著 DEG 的符号做 soft-margin logistic，把"上下调"作为独立监督信号。效果：方向准确率 +0.006（0.827→0.833）、去偏 −0.003（很小但方向一致）。

**D7 ★ 损失里的权重 $W$ 怎么定的？**
$W=1+5[\text{rank}<20]+2[\text{rank}<100]$：Top-20 DE 基因权重 6、Top-100 权重 3、其余 1。理由是生物学与后验指标都聚焦在显著 DEG 上；且 5,000 个基因中大部分没有真实变化，等权会让模型把容量浪费在噪声上。

**D8 为什么输出用低秩基底 + 残差而不是直接回归 5,000 维？**
训练扰动只有 870 个，5,000 维直接回归参数太多。用训练响应矩阵的前 32 个主方向作基底，输出 32 个系数即可，既降参数又强制预测落在"真实响应子空间"附近。PerturbNet 还额外加了一个零初始化的全秩残差（从数据里学细节）。

**D9 ★ 参数量多大？会不会过拟合？**
585,909 个参数（0.59 M），输入是 4×128/64 维知识向量，输出 5,000 维。正则手段：早停、dropout 0.1、weight decay、知识源 dropout、3 种子集成、低秩输出。CV 结果与同配置不同种子的 sd≈0.004 说明不是靠运气。

**D10 训练时怎么用记忆库？为什么排除自身？**
训练时记忆库 = 训练扰动（`tr_all`），对每个 batch 内的扰动用掩码把"它自己"从记忆里排除（`exclude_self`），否则模型会直接抄答案。测试时记忆库是全部训练扰动，测试基因本来不在里面。

**D11 为什么 3 个种子集成？**
单个种子的 CV 指标波动约 0.004，与模型间差距（0.006）同量级；3 种子平均把随机性压下去，也让最终部署模型更稳。

**D12 可以解释性具体指什么？**
三样东西：① 注意力权重 → "这个预测依据哪几个已测扰动"（RPS19 检索到 RPS17/16/24/15/14）；② 源权重 $w_{hs}$ → "这个基因该信 GO 还是 PPI/语言模型"；③ 门控 → "这次是检索起作用还是参数分支起作用"。都不是事后近似，而是前向计算的中间量。

### E 训练与实现（7 题）

**E1 ★ 训练多久？硬件要求？**
全流程 CPU 即可：4 核 7 GB。单次 PerturbFormer 训练约 100 秒；主评测（36 个模型/消融 × 5 折）约 84 分钟；流模型 5 折约 42 分钟；run_all.sh 全流程约 4 小时。GEARS 需要更大内存/GPU（与流模型不能同时跑，会 OOM）。

**E2 超参数怎么选的？**
只在开发集（第 0 折训练扰动的 10% 内部验证集，87 个基因）上扫 10 组配置；极差 Top-20 DEG 0.007、去偏 0.015，与种子噪声同量级；最终用默认配置而非最优配置，结论不依赖调参。

**E3 早停用什么指标？**
验证集上的"Top-20 DE 加权 Pearson − 10×MSE"，耐心 40 个 epoch。选这个组合是因为只看 Pearson 会忽略幅度误差，只看 MSE 会忽略"排序/方向"。

**E4 为什么用 AdamW 而不是 Adam？**
weight decay 与自适应学习率解耦，对这种小数据 + 大量线性层的模型更稳（配合 1e-3 的 wd）。学习率 1e-3，batch 64。

**E5 训练不稳定吗？怎么处理的？**
主要措施：norm_first 的 Transformer、LayerNorm、dropout、早停、集成；流模型输出层零初始化、FiLM 零初始化（初始恒等）、梯度裁剪 1.0、OneCycle 学习率。没有出现发散。

**E6 ★ 内存怎么控的（160k 细胞 × 5k 基因）？**
单细胞矩阵从不 densify：用 `anndata` backed 模式按 20,000 行分块，配稀疏指示矩阵一次算出所有扰动的均值/方差（`group_mean_var`），峰值约 3.8 GB；PCA 只在抽样细胞上拟合再投影。

**E7 代码结构？**
`src/vcp/` 是库（data/embeddings/baselines/models/flow/metrics/interpret/predictor/pipeline/plotting），`scripts/` 是 00–12 的可复现流水线 + `predict.py`，`tests/` 11 个不需数据的单元测试，`run_all.sh` 一键复现。

### F 评测与统计（10 题）

**F1 ★ 为什么按基因分折而不是按细胞分折？**
按细胞分折会让同一个扰动的其他细胞出现在训练集里，模型能"记住"该扰动的响应模式——这测的是插值能力而不是对未见基因的外推。按基因分折才是本题的目标设定。

**F2 ★ 你怎么保证没有数据泄露？**
七条：折内 PCA、折内应答谱、流模型条件用 LOO、先验知识不含表达、开发集隔离、3 种子划分、两项单元级防泄露测试（§9.6）。其中两处是验收后修的：PCA 曾用全部扰动拟合、GO 嵌入曾有跨进程不确定性。

**F3 ★ 去偏 Pearson 怎么算？为什么它能识别平凡基线？**
把预测与真实 Δ 都减去训练扰动的平均响应 $\bar\Delta_{\text{train}}$ 后再算相关。均值平移的预测恰好等于 $\bar\Delta_{\text{train}}$，去偏后为 0 向量 → 相关为 0。它衡量的是"扰动特异"部分，与 Systema 论文一致。

**F4 识别排名（rank）怎么定义？**
在 Top-20 DE 基因的并集上，计算每个"预测 i vs 真实 j"的平方距离矩阵，真实扰动 i 的归一化排名 = 比对角线更近的扰动个数/(P−1)。0=完美，0.5=随机。均值平移恰好 0.5，PerturbFormer 0.174。

**F5 噪声天花板是怎么算的？**
细胞拆两半 → 用 A 半 Δ 当预测评估 B 半 → 半数据信度 r（0.544/0.817/0.526）→ Spearman-Brown 全数据信度 2r/(1+r) → 完美预测器与全数据实测估计的相关上限 √(2r/(1+r))，对扰动平均得 0.813/0.900/0.808。

**F6 为什么用配对 Wilcoxon 而不是 t 检验？**
同一批基因上的两个模型指标是配对的，差值分布未知、可能有离群，Wilcoxon 符号秩不假设正态、对离群稳健。样本量 1,092，检验力足够。

**F7 ★ 为什么做 Holm 校正？校正后结论变了吗？**
因为对同一组基因做了 3 划分 × 6 指标 = 18 次比较，不校正会虚高显著数。Holm 控制族错误率。对**调参后 kNN**：15 胜/2 负/1 平，Holm 后计数不变；对**未调参 kNN**：15/1/2 → 14/1/3（划分 0 的方向 +0.005 失去显著）。对线性基线 18/18 不变。结论不变但要如实报告这个变化。

**F8 你报告了置信区间吗？**
报告了：每个模型指标带 95% bootstrap CI（2,000 次重采样），主图 fig2 的误差线即此；配对差值的检验统计量在 `stats_tests.csv`。

**F9 为什么换 3 种随机划分？**
模型间差距（0.006）与划分波动（0.001–0.005）同量级，单一划分可能偶然。3 种划分下排序完全一致、均值标准差很小，且 3 划分的配对比较构成 18 次检验，配合 Holm 更稳。

**F10 外部验证怎么做的？**
Replogle 训练时剔除全部 86 个 Adamson 靶基因 → 预测 Adamson 的 86 个扰动（全部是未见基因）→ 在 1,910 个共有基因上评估 → 用 41 个"两筛选都测过"的基因、以 Replogle 实测响应作为跨实验室上限。结果：达到上限的 79–86%（全基因/Top-20）。

### G 结果与对比（8 题）

**G1 ★ 你的模型比 kNN 只好 0.006，有意义吗？**
分三点答：①相关性上确实只是持平（差 ≤0.004），我们不声称领先；②稳定优势在**DEG 方向 +0.010、DEG 重合 +0.014、识别排名 −0.013**，三项在 3 种划分中全部显著；③参数化模型带来的是可解释性（邻居/源权重/门控）与可扩展性，而 kNN 的价值被证明是核心思想——所以论文式的正确表述是"多源知识检索有效，PerturbFormer 是它的可学习、可解释版本"。

**G2 为什么均值平移的全基因 Pearson 有 0.38？**
因为所有扰动共享一个系统性响应（应激、生长抑制、核糖体下调），即使完全不含扰动特异信息也能拿到 0.38。这正是文献提醒的"看起来不错的陷阱"，也是必须看去偏指标的原因。

**G3 ★ GEARS 的对比公平吗？**
做了一次公平重跑：同一第 0 折、同一训练/验证/测试基因，GPU 上把预算提到 30/50 细胞/扰动、5,000 对照、20 epoch。GEARS+KD 去偏 0.227/0.231，仍远低于 PerturbFormer 0.504（50 细胞版全基因 +0.227，p<1e-24）。保留的限定：单折、单数据子集、50 细胞仍低于中位数 115，无法完全分离"细胞数"与"对照比例"的贡献。

**G4 为什么 PerturbNet 的方向准确率更高？**
0.847 vs 0.833。可能原因：检索输出是多个已测响应的加权平均，弱 DEG 的符号被平均化；参数化解码器可以单独调每个基因的符号。但分层看全部 67 万显著 DEG 时 PerturbFormer 更高（0.878 vs 0.870），PerturbNet 的优势只在 |Δ|<0.05 的最弱档（0.756 vs 0.741）。

**G5 单细胞模型打不过"借用相似扰动细胞"的基线，那流模型有什么用？**
①它给出逐细胞反事实（$x_0\mapsto x_1$），借用细胞只能给群体；②相对"只平移均值"它有明确改进（能量距离 −7%、MMD −17%、方差 −17%，p<1e-30）；③持平本身是重要发现：强检索基线很难被超越，未来应把力气放在均值预测上（Oracle 平移的能量距离只有 0.227）。④我们如实报告失败尝试（方差条件在开发集变差，未采用）。

**G6 0.48 的去偏相关算高还是低？**
相对上限 0.808 是 59%；相对基线（线性 0.430、kNN 0.473）是显著提升；绝对值受测量噪声（每个扰动中位 115 个细胞）限制。可信的说法是"达到了噪声上限的近 60%，且显著优于所有同等调参的基线"。

**G7 为什么 Adamson 内部评测的分数都那么高？**
该数据每个扰动约 500 个细胞，测量信度极高（上限 0.986/0.946）；且 86 个扰动都聚焦 UPR，共同响应强。即便如此，均值平移的去偏相关仍为 0、PerturbFormer 0.544 最高——信度高时方法优势更清楚。

**G8 你的结果和文献能对上吗？**
能：①均值平移的"假象"与 Systema 的结论一致；②线性基线很强、深度模型不占大优势，与 Ahlmann-Eltze 2025 一致；③GEARS 在我们的公平设定下不占优，与其评测方向一致。差别在于我们证明了"多源知识检索"能稳定超过线性基线，并在 DEG 层面超过调参 kNN。

### H 生物学（6 题）

**H1 ★ 为什么复合体成员可预测？**
同一复合体的亚基被敲低后功能缺失效应高度一致（核糖体、蛋白酶体、Mediator），只要有一个成员测过，其余成员就能被"借"出来。数据证据：同类 10 近邻比例 78%（随机 5%）；CORUM 同复合体比例 42.7%（随机 2.7%）。可预测性排名：CCT/TRiC 0.83、核糖体 0.82、RNA 外切体 0.74、Mediator 0.73、蛋白酶体 0.71；转录调控类最差（Pol II 0.47）。

**H2 GATA1 为什么失败？**
GATA1 是红系主转录因子，K562 是红白血病细胞系。训练集里没有效应类似 GATA1 的基因，模型从 GO/PPI/GenePT 只知道"它是一个转录因子"，于是借了 ATF4、MAX 等一般转录因子：共性的 MYC 靶基因下调预测对了，红系特异的血红蛋白基因方向预测反了（预测上调、实测下调）。教训：**谱系特异的主调控因子无法靠相似性外推**，这正是最需要实验的地方；工具也已用"低"可靠性评级提示这一点。

**H3 通路层面的结论可靠吗？**
50 条 Hallmark 通路，跨扰动平均相关 r=0.587（kNN 0.579、Linear 0.494、均值平移 −0.057）；变化最大的 25% 通路方向正确率 93.8%。最准的是 DNA 修复 0.74、氧化磷酸化 0.71、干扰素 α 应答 0.70；MYC 靶基因 0.56/0.58。

**H4 知识的来源偏好吗？**
有。整体 GO 权重最高；Mediator 类更信 PPI（0.41），翻译起始因子更信 GenePT（0.31），胞质核糖体三源近乎平均（0.30/0.29/0.30）。模型是按基因自适应的，不是固定权重。

**H5 这个工具能直接用于药物靶点发现吗？**
可以作为**优先级排序**工具，但要配合可靠性评级与实验验证：①它对"功能上有已测邻居"的基因可靠（核糖体/蛋白酶体类 0.8 上下）；②对谱系特异调控因子不可靠；③只覆盖 K562 一个细胞系、CRISPRi 一种扰动方式。报告里明确建议：下一轮实验应优先测"知识空间中离已测基因最远"的基因（主动学习）。

**H6 敲低一个基因，为什么有些基因上调？**
因为存在去抑制/代偿：例如敲低核糖体蛋白会触发核糖体生物合成基因的反馈、敲低蛋白酶体亚基会诱导蛋白稳态应激（SQSTM1、UBC 上调）。模型的预测保留这些反向调节（PSMB5 案例：MYC 靶基因下调 + EMT/SQSTM1 上调）。

### I 局限、批评与改进（8 题）

**I1 ★ 你这项工作最大的局限是什么？**
三点按重要性排序：①**泛化本质上受限于"是否存在功能相似的已测基因"**——这既是方法的机理也是天花板（先验相似度与去偏相关的 Spearman ρ=0.52）；②只做了 K562 单细胞系、单基因敲低（CRISPRi），没有跨细胞系/组合扰动；③单细胞层面流模型没有超过免训练的检索基线，逐细胞映射的精度仍受 100 维 PCA 与均值预测误差限制。

**I2 如果给你更多算力/时间，先做什么？**
按优先级：①跨细胞系（Replogle RPE1/HepG2/Jurkat）把"细胞背景"作为显式输入——这是当前模型最大的结构性缺失；②组合扰动（Norman 2019）与遗传相互作用；③不确定性估计 + 主动学习（用先验新颖度选下一批实验）；④更好的单细胞生成（在基因空间或更高维潜空间做流匹配）。

**I3 为什么不做跨细胞系？**
数据结构上需要把"细胞类型"作为显式条件、并在多个筛选间对齐基因与扰动；工作量与数据规模都超出本次课程设计的范围，报告已列为展望。

**I4 有做不确定性估计吗？**
没有严格的后验不确定性（没有做 MC dropout / 深度集成方差）。替代方案是**可靠性评级**：用"查询基因与已测扰动的最大先验相似度"分三档，用交叉验证校准（三档去偏 0.32/0.47/0.65），在预测前就能算，对使用者更有用。承认这是启发式而非严格不确定性。

**I5 你的模型对超参敏感吗？**
开发集扫描 10 组配置，Top-20 DEG Pearson 极差 0.007、去偏 0.015，同配置不同种子 sd≈0.004；最终用默认配置。所以对超参不敏感，结论不依赖调参。

**I6 方向准确率 87.8% 是不是因为大部分基因本来就是下调/不变的？**
不是"因为不平衡"：①我们在**显著 DEG**（FDR<0.05）上评估，并分别报 Top-20/Top-100；②均值平移在同一批基因上只有 0.739（弱变化档 0.462，接近随机），说明方向确实需要扰动特异信息；③按 |Δ| 分层显示准确率随幅度单调上升（0.741→0.945），符合"信噪比决定可预测性"的预期；④另外报了 AUROC 0.946 以排除阈值效应。

**I7 单细胞评测用 PCA 空间，会不会掩盖问题？**
会有限制（基因细节被 100 维截断），我们在报告局限里写了。缓解：①同时报告解码回基因空间后的伪批量指标（与伪批量预测一致，0.556 vs 0.567）；②报告"每折 Δ 落在潜空间的能量比例"（测试 61%、训练 62%），说明潜空间保留了主要效应；③能量距离/MMD 在 scPerturb 中也是标准做法。

**I8 如果有人复现不出来怎么办？**
`run_all.sh` 一键复现（CPU 4 小时），数据全部公开可下载（`00_download_data.sh`），结果表与图都由脚本生成；11 个单元测试不依赖数据；关键随机性都固定种子；模型权重与预测示例已入库（`models/k562/`、`results/predictions/`）。唯一无法保证的是网络下载源可用性。

## 12 最容易被问倒的 10 个问题（含第二层追问）

**Q1 ★★ "你的创新点到底是什么？"**
第一层答案：把"检索已测扰动"显式做成**知识核交叉注意力**——注意力分数由多源先验相似度构成、初始化为多源 kNN、只学修正；再加查询相关的知识源权重、KD 领域规则、方向多任务损失，并用留一条件把伪批量预测接入流匹配。第二层（如果追问"这算创新吗"）：学术上更准确的定位是**设计+严格评测**：我们把"多源知识检索"这一思路做到可学习、可解释，并用 3 划分 × 3 种子 × 18 指标 + Holm + 噪声上限 + 同等调参基线 + GEARS 公平重跑，证明它稳定优于线性基线与已发表方法。不夸大算法新颖性。

**Q2 ★★ "你是不是在测试集上调参了？"**
没有在测试折上调参。设计与选参只在开发集（第 0 折训练扰动内的 87 个基因）；但诚实说明：开发集基因在第 1–4 折里是测试基因，所以严格意义上只有第 0 折的 219 个测试基因"从未被设计过程接触"，我们单独报告了这一折，优势反而更大（去偏 +0.012 vs +0.005）。另外我们曾在校验阶段发现并修复了两处轻度泄露（PCA 拟合范围、GO 嵌入不确定性），并重跑全部结果。

**Q3 ★★ "为什么不用 scGPT / Geneformer / 更大的预训练模型？"**
①这类细胞基础模型主要在海量细胞图集上做表达重建，独立评测显示它们在扰动响应预测上并不优于简单基线（Ahlmann-Eltze 2025）；②我们的任务只有约 870 个训练扰动，真正的信息在"功能相似性"上，检索式结构比堆参数更对症；③我们以 GenePT（语言模型基因嵌入）的形式已经引入了"大模型先验"，并且消融证明它有独立贡献（−0.024）；④算力约束（4 核 CPU）使全流程可复现成为可能，这本身是课程要求的一部分。若给 GPU，下一步会做的是跨细胞系而不是换更大的模型。

**Q4 ★★ "核糖体/蛋白酶体好预测，是不是意味着任务很简单？"**
恰恰相反，这说明**任务的难点被定位清楚了**：功能上有已测近邻的基因（同复合体）可预测 0.7–0.8，而谱系特异的调控因子（GATA1 0.33）不可预测。整体 0.48 的去偏相关正是这两类混合的结果。可预测性的强规律（与先验相似度 ρ=0.52）本身就是有意义的科学结论，并且直接给出了"下一批该测什么"的策略。

**Q5 ★★ "K562 是个异常细胞系（白血病、超三倍体），结论能推广吗？"**
不能直接推广到其他细胞系，这是明确的局限。K562 是 Perturb-seq 基准最常用的细胞系，适合方法比较；但"细胞背景"决定了扰动响应，报告把跨细胞系（RPE1/HepG2/Jurkat）列为最重要的下一步，并指出当前模型没有显式的细胞类型条件。可以补充：外部验证虽换了实验室但仍同细胞系，所以跨实验室 79–86% 的上限也说明"技术差异"本身很大。

**Q6 ★ "流模型没打过免训练基线，是不是没必要做？"**
不是。它解决的是题目要求的"输出扰动后细胞状态"这一层：①逐细胞反事实映射是检索基线给不出的；②相对只平移均值有显著改进（p<1e-30）；③它的条件来自 PerturbFormer，把两个层次串成一个系统（输出可解释、可复现）；④持平结果是重要的负面发现，避免了"堆一个复杂生成模型就更好"的错觉，也指出未来改进应聚焦均值预测。我们还公开了一个失败的改进（方差条件）。

**Q7 ★ "为什么不预测全部约 2 万个基因，只用 5000 个？"**
数据（GEARS 预处理版）只提供 5,000 个高变基因的表达；这是该基准的通行设定，保证与文献可比。局限是低表达/非高变基因不在评估范围。部署端我们做了 21,449 个基因的先验嵌入，可以查询任意基因（预测其"对 5,000 个测量基因的效应"）。

**Q8 ★ "你的方法本质上是不是就是 kNN？"**
结构上初始化时**确实等价于多源 kNN**，这是我们刻意设计的归纳偏置；但训练后它多了：可学习的源内度量 $A_s$、查询相关源权重、多头不同温度、top-k 稀疏、门控参数化分支、KD 规则、方向损失，因此稳定优于固定 kNN（DEG 层面）并给出可解释证据。诚实地说：核心是"多源知识检索"，PerturbFormer 是它的可学习版本——这也是我们把它写成结论而不是宣称算法突破的原因。

**Q9 ★ "DEG 方向 87.8% 听起来很高，会不会是指标太宽松？"**
指标定义严格：只在 FDR<0.05 的显著 DEG 上算；用真实数据的 |t| 排序取 Top-20/Top-100；另外报全部 672,827 个显著 DEG 的准确率与 AUROC。分层显示弱变化基因只有 74%，均值平移在同一批基因上只有 0.739、弱变化档 0.462（近随机）——说明这个数字反映真实能力而不是标签不平衡。

**Q10 ★ "如果模型错了，代价是什么？怎么让使用者知道？"**
每次预测都附**可靠性评级**（高/中/低，按与已测扰动的最大先验相似度分档，用 CV 校准：三档去偏 0.32/0.47/0.65），并列出"依据的已测扰动与权重、知识源权重"，让使用者判断证据是否充分；报告还给出明确的失败模式（谱系特异调控因子、弱效应扰动）。建议的用法是"优先级排序 + 实验确认"，而不是直接下结论。

### 13.1 推荐演示（30 秒—1 分钟，最稳）

```bash
conda activate vcp                       # 或直接用装了依赖的 python
```

- 单细胞：生成 300 个扰动后细胞，潜空间平均位移 6.14

### 13.2 演示要讲的三句话

1. "MYC 在训练筛选里没被测过，所以这是真正的未见基因预测。"

3. "它同时给出可靠性评级：MYC 是'中'；如果换成 GATA1，评级会掉到'低'，提示这个结论需要实验确认。"

## 15 关键数字速查（上台前看这一页）

**数据**
- Replogle：162,751 细胞 / 1,092 扰动 / 5,000 基因 / 10,691 对照 / 每扰动中位 115 细胞
- Adamson：68,603 细胞 / 86 扰动 / 5,060 基因；共有基因 1,910；两筛选都扰动 41 个
- 先验覆盖（扰动基因）：GO 99.6% / PPI 97.6% / GenePT 99.5% / 应答谱 37.7%
- 全基因组先验：21,449 基因（GO 88.0% / PPI 75.5% / GenePT 91.2%）

**模型**
- PerturbFormer 585,909 参数；3 种子集成；知识核 top-20；d=128；2 层；4 头
- 流匹配 1,427,044 参数；100 维 PCA；OT 配对；20 步中点积分；8,000 步训练
- 输出维度 5,000；响应低秩基底 32 维

**主结果（1,092 未见基因，5 折 OOF）**
- PerturbFormer+KD：0.573 / 0.746 / 0.480 / 0.833 / 0.285 / 0.174
- kNN+KD：0.567 / 0.749 / 0.473 / 0.828 / 0.278 / 0.175
- Linear+KD：0.526 / 0.696 / 0.430 / 0.793 / 0.237 / 0.222
- PerturbNet+KD：0.552 / 0.738 / 0.443 / 0.847 / 0.262 / 0.191
- Mean-shift：0.382 / 0.464 / 0.000 / 0.643 / 0.091 / 0.500
- 噪声上限：0.813 / 0.900 / 0.808
- 调参后 3 划分平均：PF 0.577/0.749/0.479/0.831/0.286/0.175；kNN 0.573/0.745/0.477/0.821/0.271/0.188；Linear 0.551/0.701/0.452/0.781/0.225/0.265

**对比结论**
- vs 调参 kNN：18 次 #15 胜 / 2 负 / 1 平（Holm 后不变）
- vs 调参 Linear：18/0/0；去偏 +0.027
- vs PerturbNet：去偏 +0.037，方向 −0.014
- vs GEARS+KD（同折）：去偏 0.504 vs 0.231（50 细胞重跑）

**DEG 方向**：全部 672,827 个显著 DEG 准确率 0.878，AUROC 0.946；|Δ|<0.05 为 0.741，>0.2 为 0.932+

**单细胞**：能量距离 CFM 1.007 / 只有一个均值平移 1.080 / 借用相似扰动细胞 0.970 / Oracle 0.227；MMD 0.042 vs 0.051；方差误差 0.216 vs 0.260

**外部验证**：PF 全基因 0.394（上限 0.458，86%）、Top-20 0.492（上限 0.624，79%）、去偏 0.265（上限 0.398，67%）；kNN 在外部略优（Top-20 0.506）

**Adamson 内部**：PF 0.857/0.950/0.544/0.960/0.172（全指标最优）

**生物解释**：CCT/TRiC 0.83、核糖体 0.82、RNA 外切体 0.74、Mediator 0.73、蛋白酶体 0.71、Pol II 0.47、未归类 0.38；通路 r=0.587；CORUM 同复合体 42.7%（随机 2.7%）；失败相关 ρ=0.52（先验新颖度）/0.49（效应强度）；可靠性三档 0.32/0.47/0.65

**工程**：全流程 CPU 4 核约 4 小时；单次 PerturbFormer 训练约 100 秒；11 个单元测试；4 次提交的结构见 §11 J5
